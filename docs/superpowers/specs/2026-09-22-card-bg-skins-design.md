# 每人独立的卡牌皮肤与背景

2026-09-22

把「主题」从房主决定的房间设置，拆成每个玩家自己的本地外观选择，并新增卡牌皮肤这条独立维度。

## 现状

- `room.settings.theme` 存在服务端，房主创建房间时选（澳门风云 / 仙风道骨），**全员共享一个值**
- 主题除了背景图，还带一整套文案替换（加注→出招、底池→彩头），以及三个操作按钮的一套外观（`isXianfeng`）
- 卡牌只有一套（古风 sprite），没有切换的概念
- 英雄已经是每人一份（服务端 `player.heroId` + `selectHero`，无阶段限制，实时广播，**同房间内不可重复**）
- 牌局中点自己的头像弹的是嘲讽表情选择器
- `stats: { handsPlayed, wins }` 与筹码挂在玩家记录上、按**昵称**持久化，与 `heroId` 无关

## 目标

1. 每人自选卡牌皮肤（4 种）与背景（4 种），互不影响，不同步给别人
2. 首页加入前可预设，牌局中随时可改，即时生效
3. 换英雄从等待房搬进同一个面板
4. 筹码、战绩、发牌与结算逻辑一律不受影响

## 决策

### 文案替换：取消

全员统一用标准德州术语（弃牌/跟注/加注/底池）。`THEMES` 里的整个 `text` 字段和各处 `tx()` 调用删除，仙风道骨退化成一张纯背景图。

理由：背景变成每人各选后，若文案跟着背景走，同一局里不同人看到的措辞会不一致；若继续由房主统一决定，就得同时维护房间级和个人级两套状态。取消是唯一没有副作用的选项。

### 按钮外观：保留，跟着背景走

`isXianfeng` 管的不是文案而是操作按钮的视觉（半透明发光 vs 厚重 3D）。这是样式不是措辞，保留，改成背景注册表里的一个 `buttonStyle` 字段，四个背景各配一套。纯本地渲染，各看各的。

### 旧版卡牌：保留 CSS 画法，不烘焙成图

`Card.jsx` 分派两条渲染路径：`legacy` 走 CSS，其余三套走 sprite。

理由：旧版是 CSS 矢量绘制，任何尺寸都清晰且**零图片下载**。它又正好是默认皮肤，意味着新玩家进来一张卡牌图都不用下载，三套美术图变成按需加载。烘焙成 sprite 虽然能统一成一条代码路径，但会把矢量变位图、白白多 600KB。

### 房间主题设置：删除

服务端 `settings.theme` 与首页创建房间表单里的主题选择器一并移除。背景完全个人化后，房主不该决定任何人看到什么。

## 设计

### 状态与存储

三个选择全部是客户端本地状态：

| 项 | localStorage 键 | 默认值 | 是否同步 |
|---|---|---|---|
| 卡牌皮肤 | `poker_deck` | `legacy` | 否 |
| 背景 | `poker_bg` | `macau` | 否 |
| 英雄 | `poker_hero`（已存在） | 无 | 是，走服务端 |

沿用现有 `poker_hero` / `poker_nickname` 的模式：按设备记，不跨设备同步。

### 卡牌皮肤注册表 `src/data/decks.js`

| id | 名称 | 实现 | 资源目录 |
|---|---|---|---|
| `legacy` | 旧版 | CSS 绘制 | 无 |
| `classic` | 经典 | sprite | `public/cards/classic/` |
| `gufeng` | 古风 | sprite | `public/cards/gufeng/` |
| `cyber` | 赛博朋克 | sprite | `public/cards/cyber/` |

每套 sprite 皮肤含 `deck-sheet.webp`（13×4，列 = VALUES 下标、行 = SUITS 下标）与 `card-back.webp`。
取牌数学不变。现有 `public/cards/*.webp` 挪进 `gufeng/`。

`index.html` 里对古风资源的两行 `preload` 删除——默认已不是古风，无条件预载是浪费。

### 背景注册表

`THEMES` 降级为纯前端的背景表，每项 `{ id, name, bg, bgStyle, buttonStyle, thumb }`：

| id | 名称 | 图 |
|---|---|---|
| `macau` | 澳门风云 | 现有 `bg2.png` |
| `xianfeng` | 仙风道骨 | 现有 `天宫.jpg` |
| `parlor` | 私人牌桌 | 新增 |
| `cyber` | 赛博朋克 | 新增 |

公共牌与底池固定定位在 `top: 47%`，与背景图无关；各背景的牌桌大小位置不同，靠每项自己的 `bgStyle` 对齐（仙风道骨现有 `top:-18%, height:118%` 就是这个机制）。两张新背景的桌子比 `bg2.png` 更大更近，需要逐张截图微调——**这是本次最可能返工的地方**。

### 外观面板

牌桌右上角常驻齿轮按钮，等待房与牌局中都在，随时可点、即时生效。三栏：

- **英雄** —— 别人选过的置灰（沿用现有不可重复规则），选中即 `socket.emit('selectHero')`
- **卡牌** —— 每项用 `Card` 组件渲染该套真实的 A♠ 作预览，零额外资源
- **背景** —— 每项显示缩略图，另行生成 4 张小图，避免为显示预览下载 4 张完整大图

点头像保持弹嘲讽表情不变。

### 首页

新增「卡牌与背景」按钮，与现有「选择你的英雄」并排。删除创建房间表单里的主题选择器。

## 不做

皮肤解锁与成就、房主推荐标记、跨设备同步、卡牌切换动画。

## 验证

- 四套卡牌各用真实 Chromium 截图，逐张核对 52 牌落格、卡背与非法牌号回落
- 四套背景各截一张手机尺寸牌桌图，确认头像圈与桌面对齐
- `npm run build` 通过
- 确认 `stats` 与筹码在换英雄、换皮肤前后不变
